Privacy policy

Vaulted Logic Tools · last updated 28 October 2026

What this app is

A personal tool used only by its owner, to let the owner's own assistant software on the owner's own computer work with the owner's own Google account. It is not offered to anyone else.

What data it accesses

Only the Google services the owner approves on the Google sign-in screen (for example Gmail, Drive, Docs, Sheets, Slides, Calendar, Google Analytics, Search Console, YouTube), and only for the owner's own account.

How data is used and stored

  • Data is used only to carry out tasks the owner asks for.
  • Sign-in tokens are stored encrypted on the owner's own computer.
  • No data is sold, rented, shared with third parties, or used for advertising.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The owner can remove this app's access at any time at myaccount.google.com/permissions. Removing access stops all further use.
